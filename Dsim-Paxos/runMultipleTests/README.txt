1. unzip all folder in one
2. There will be two file node indexMultipleServerNode.js & runMultipleServer.sh
3. Copy the runMultipleServer.sh in the home/username folder.
4. change the tar_dir in runMultipleServer.sh to the dir to to the main protocol code folder.
4. like "npm run node1"
